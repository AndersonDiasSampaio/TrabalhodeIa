Camada de Proteção
Filtro de Rotas

Todas as requisições para rotas internas são interceptadas e validadas pelo Spring Security Filter Chain.

Banco de Dados
H2 / JPA Hibernate

Usuários cadastrados são persistidos na entidade Usuario com verificação de unicidade.

Mecanismo de Visão
Thymeleaf Engine

Templates processados dinamicamente no lado servidor com integração direta ao Spring Security 6.

Criptografia
BCrypt Hashing

As senhas digitadas no cadastro são protegidas com salt e hashing forte através da interface PasswordEncoder.

Como funciona a proteção de rotas no sistema?

Se qualquer visitante tentar acessar diretamente a URL /bem-vindo sem ter efetuado login prévio, o Spring Security interceptará a requisição e redirecionará automaticamente para /login. Novos usuários podem se registrar em /cadastro e logar imediatamente.
